      Moto Lines Studio 
      
  
      Created by OB Industries. A local editor for MX Bikes gfx.cfg hand and chain lineups.
      
  
      What it doesn’t do
      
  
        
    
      • It shows a static pose. Suspension, steering and rider IK aren’t simulated.
        • 
    
      • The chain guide is a reference line to the template rear axle, not the game’s chain.
        • 
    
      • Bike placement is verified only for the original Husqvarna; other EDFs use the MXB template.
        • 
    
      • The hand overlay uses the real stock glove mesh; the game’s wrist orientation isn’t verified.
        • 
  
      
  
      Always test final lineups in MX Bikes. Recovery copies of every overwritten file are kept in the backups folder.
